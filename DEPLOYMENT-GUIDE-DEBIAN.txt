==========================================
GUÍA COMPLETA DE DESPLIEGUE - SISTEMA GESTIÓN COLEGIO
==========================================

FECHA: 08/09/2025
SISTEMA: Debian 12 (Bookworm) en VirtualBox
APLICACIÓN: NestJS + TypeORM + MySQL + Docker

==========================================
1. CONFIGURACIÓN INICIAL DEL SERVIDOR DEBIAN
==========================================

# Actualizar sistema
sudo apt update && sudo apt upgrade -y

# Instalar dependencias necesarias
sudo apt install -y curl wget git docker.io docker-compose python3 python3-pip openssl

# Agregar usuario al grupo docker
sudo usermod -aG docker $USER

# Habilitar Docker al inicio
sudo systemctl enable docker
sudo systemctl start docker

# Reiniciar sesión para aplicar cambios
# (cerrar y abrir terminal)

# Verificar instalación
docker --version
docker-compose --version
systemctl status docker

==========================================
2. CONFIGURACIÓN DE RED VIRTUALBOX
==========================================

IMPORTANTE: Para acceso desde red local

1. Cerrar máquina virtual
2. En VirtualBox Manager:
   - Seleccionar VM
   - Settings → Network → Adapter 1
   - Attached to: "Bridged Adapter"
   - Name: Seleccionar adaptador de red (WiFi/Ethernet)
   - Promiscuous Mode: "Allow All"
3. Reiniciar VM

# Verificar IP de red local
hostname -I
# Debe mostrar IP tipo 192.168.1.x

# Verificar conectividad de red
ping -c 3 8.8.8.8

==========================================
3. CONFIGURACIÓN DE FIREWALL (UFW)
==========================================

# Instalar UFW si no está instalado
sudo apt install -y ufw

# Habilitar firewall y permitir puerto 443
sudo ufw allow 443/tcp
sudo ufw allow 22/tcp  # SSH
sudo ufw allow 80/tcp  # HTTP (opcional)
sudo ufw --force enable

# Verificar estado
sudo ufw status verbose

# Verificar que el puerto esté abierto
sudo netstat -tlnp | grep :443

==========================================
6. CONFIGURACIÓN DE SSL
==========================================

# Crear directorio SSL
mkdir -p ssl

# Generar certificado autofirmado
openssl req -x509 -newkey rsa:4096 -keyout ssl/server.key -out ssl/server.crt -days 365 -nodes -subj "/C=PE/ST=Lima/L=Lima/O=Colegio/CN=localhost"

# Configurar permisos correctos para SSL
chmod 600 ssl/server.key
chmod 644 ssl/server.crt

# IMPORTANTE: Cambiar propietario al usuario del contenedor Docker
# Verificar el usuario del contenedor después de iniciarlo
docker compose up -d
docker compose exec app id
# Usar el UID y GID del comando anterior (ejemplo: 1001:65533)
sudo chown -R 1001:65533 ssl/

# Verificar certificados y permisos
ls -la ssl/

# Verificar contenido del certificado
openssl x509 -in ssl/server.crt -text -noout

==========================================
15. SOLUCIÓN DE PROBLEMAS COMUNES
==========================================

# Problema: "No migrations are pending"
# Solución: Verificar que data-source.ts tenga:
# migrations: ['dist/database/migrations/*.js']

# Problema: SSL_ERROR_SYSCALL
# Solución: Usar -k en curl o desactivar verificación SSL

# Problema: No se puede acceder desde red externa
# Solución: Verificar configuración de red VirtualBox (Bridged Adapter)

# Problema: Puerto 443 no accesible
# Solución: Verificar firewall (sudo ufw allow 443/tcp)

# Problema: Contenedores no inician
# Solución: Verificar logs (docker compose logs)

# Problema: Docker no inicia
# Solución: 
sudo systemctl start docker
sudo systemctl enable docker

# Problema: Permisos de archivos
# Solución:
sudo chown -R $USER:$USER gestion-backend-ar/
chmod -R 755 gestion-backend-ar/

# Problema: Certificados SSL
# Solución: Regenerar certificados
rm -rf ssl/*
openssl req -x509 -newkey rsa:4096 -keyout ssl/server.key -out ssl/server.crt -days 365 -nodes -subj "/C=PE/ST=Lima/L=Lima/O=Colegio/CN=localhost"

16. BACKUP Y RESTAURACIÓN
==========================================

# Backup de base de datos
docker compose exec mysql mysqldump -u root -p gestion_academica_ar > backup_$(date +%Y%m%d_%H%M%S).sql

# Restaurar base de datos
docker compose exec -i mysql mysql -u root -p gestion_academica_ar < backup_file.sql

# Backup de archivos de aplicación
tar -czf app_backup_$(date +%Y%m%d_%H%M%S).tar.gz gestion-backend-ar/

# Backup de configuración del sistema
sudo dpkg --get-selections > installed_packages.txt
sudo cp /etc/ufw/user.rules ufw_backup.rules

19. CONFIGURACIÓN AVANZADA DE DEBIAN
==========================================

# Configurar swap si es necesario
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

# Configurar límites del sistema
echo '* soft nofile 65536' | sudo tee -a /etc/security/limits.conf
echo '* hard nofile 65536' | sudo tee -a /etc/security/limits.conf

# Configurar kernel parameters
echo 'vm.max_map_count=262144' | sudo tee -a /etc/sysctl.conf
sudo sysctl -p

# Configurar logrotate para logs de aplicación
sudo tee /etc/logrotate.d/gestion-colegio << EOF
/home/$USER/gestion-backend-ar/logs/*.log {
    daily
    missingok
    rotate 30
    compress
    delaycompress
    notifempty
    create 644 $USER $USER
}
EOF

==========================================
NOTAS IMPORTANTES PARA DEBIAN
==========================================

1. Debian 12 (Bookworm) es la versión estable actual
2. Docker se instala desde los repositorios oficiales de Debian
3. UFW es el firewall por defecto en Debian
4. systemd es el sistema de init por defecto
5. Los logs del sistema se manejan con journalctl
6. La configuración de red se maneja con systemd-networkd
7. Los certificados SSL se generan con OpenSSL
8. La aplicación es accesible desde cualquier dispositivo en la red local
