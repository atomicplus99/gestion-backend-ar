ESTADO: ✅ CORREGIDO - Rutas funcionando correctamente

================================================================================
PROBLEMA IDENTIFICADO
================================================================================

El endpoint GET /alumnos/estado estaba fallando con error 404 porque la ruta 
@Get(':id') en el controlador de Alumno estaba capturando la petición antes 
de que llegara al controlador de estados de alumnos.

ERROR ENCONTRADO:
-----------------
```
GET /alumnos/estado
[Nest] ERROR [AlumnoController] ❌ [Controller] Error al obtener alumno: Alumno estado no encontrado
NotFoundException: Alumno estado no encontrado
```

CAUSA RAÍZ:
-----------
- La ruta @Get(':id') capturaba cualquier string después de /alumnos/
- "estado" se interpretaba como un ID de alumno
- El sistema intentaba buscar un alumno con ID "estado"
- Nunca llegaba al controlador de estados que maneja /alumnos/estado

================================================================================
SOLUCIÓN IMPLEMENTADA
================================================================================

Se modificaron las rutas del controlador de Alumno para evitar conflictos con 
rutas específicas como /estado.

CAMBIOS REALIZADOS:
===================

📁 ARCHIVO: src/entities/alumno/infraestructure/adapters/inbound/controllers/alumno.controller.ts

🔧 RUTAS MODIFICADAS:
=====================

ANTES (PROBLEMÁTICO):
---------------------
```typescript
@Get(':id')                    // ❌ Capturaba /alumnos/estado
@Delete(':id')                 // ❌ Conflicto potencial
@Get(':id/usuarios')           // ❌ Conflicto potencial
```

DESPUÉS (CORREGIDO):
--------------------
```typescript
@Get('id/:id')                 // ✅ /alumnos/id/{uuid}
@Delete('id/:id')              // ✅ /alumnos/id/{uuid}
@Get('id/:id/usuarios')        // ✅ /alumnos/id/{uuid}/usuarios
```
